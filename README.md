# Hv13 для DLE 21

Светлый адаптивный шаблон блога и новостного сайта для **DataLife Engine 21.0**. Тёмная шапка, светлые карточки публикаций и сиреневые акценты. Адаптация: [The88788.com](https://the88788.com/).

[Скачать версию 1.0.0](https://github.com/The88788/Hv13-DLE21/releases/tag/v1.0.0) · [Описание и скриншоты](https://the88788.com/files/dle/templates/dle21/135-hv13-dle-21.html)

## Возможности

- Адаптивная вёрстка для компьютеров, планшетов и телефонов.
- Карточки публикаций с обложками, категориями, тегами и рейтингом.
- Мобильная навигация, поиск и быстрые поисковые подсказки.
- Полная публикация, связанные материалы и стандартные комментарии DLE.
- Оформление регистрации, авторизации, профиля, личных сообщений и обратной связи.
- Боковая колонка с категориями, популярными публикациями и последними комментариями.

## Совместимость

Проверено на **DLE 21.0 с PHP 8.3**. Используется штатная jQuery 3.7.1 из DLE и локальный Bootstrap 4.6.2 с Popper. Дополнительные PHP-модули не нужны.

Совместимость с другими версиями DLE не заявляется. В шаблоне одна светлая тема. Магазин, Whoonline и слайдер не входят в комплект.

## Установка

1. Сделайте резервную копию текущего шаблона и настроек сайта.
2. Скачайте ZIP из [релиза](https://github.com/The88788/Hv13-DLE21/releases/tag/v1.0.0) и распакуйте его.
3. Скопируйте папку `Hv13` в каталог `templates` установленного DLE 21.0.
4. Выберите `Hv13` в настройках сайта, оставьте ветку **jQuery 3** и очистите кеш DLE.
5. Заполните категории и публикации вашего сайта. Для обложек поддерживается дополнительное поле `poster` типа «Изображение»; при его отсутствии используется изображение текста новости или резервная картинка.

Подробная инструкция `INSTALL.md` и файл контрольной суммы доступны в составе материалов релиза. Ядро CMS и демонстрационная база не включены.

## Настройка шаблона

| Файл | Назначение |
|---|---|
| `Hv13/main.tpl` | Основная разметка и футер |
| `Hv13/modules/head.tpl` | Шапка и главное меню |
| `Hv13/modules/foot.tpl` | Боковая колонка, блоки услуг и VPS |
| `Hv13/categorymenu.tpl` | Меню категорий |
| `Hv13/css/hv21.css` | Цвета, отступы и адаптивная вёрстка |
| `Hv13/shortstory.tpl` | Карточка публикации |
| `Hv13/fullstory.tpl` | Полная публикация |

Пути `{THEME}/../../` поддерживают установку в корне домена и подпапке. Файлы `frame.css` и `preview.css` используются редактором и админпанелью DLE.

## Проверка и ограничения

Проверены основные страницы, мобильное меню, поиск, авторизация, профиль, комментарии, цитирование и открытие редактирования, формы регистрации, личных сообщений и добавления публикации. Проверен перенос в подпапку.

Доставка почты и личных сообщений, загрузка файлов и отправка новой публикации не проверялись полным циклом. Эти функции зависят от настроек сервера и прав DLE. Для почты настройте SMTP.
